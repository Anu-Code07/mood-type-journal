# MoodType Journal — Premium Concept Blueprint

## Positioning

MoodType Journal is not a notes app.  
It is an emotional art engine where thoughts become cinematic typography and shareable visual memories.

## Signature Loop

1. User writes a journal moment.
2. AI analyzes mood + emotional energy.
3. Entry is transformed into animated typography.
4. AI wallpaper/poster is generated.
5. User customizes and exports.
6. Memory is saved to emotional timeline.

## Visual Language

- Japanese minimal layout rhythm
- Frosted glass cards and soft blur layers
- Ambient gradient atmospheres
- Typography-led hero moments
- Slow breathing micro-motion and haptic pairing

## Core Feature Matrix

### Journal Capture
- free text
- quick tags
- voice entry hook
- emoji emotional dial
- dynamic cursor + breathing background

### Transformation Engine
- case transforms + spacing modes
- poetic and kinetic styles
- per-letter animation potential
- ripple, wave, elastic, flicker animation presets

### Wallpaper Studio
- quote extraction
- style palette selection
- texture + blur + glow tuning
- lockscreen ratio framing
- AMOLED dark mode compositions

### Export Modes
- static HD / ultra
- animated short reel
- wallpaper apply action hooks
- social story-safe exports

### Timeline Intelligence
- emotional streak graph
- dominant mood palette history
- healing pattern detection
- reflective daily summaries

## Advanced Future Features

- AI-generated motion backgrounds
- ambient music snippets from mood vector
- lockscreen widgets
- emotional heatmap calendar
- touch-reactive dynamic typography
- haptic choreography synced with text transitions

## Engineering Notes

- Keep UI declarative and lightweight.
- Offload heavy render/export to isolates.
- Cache generated wallpapers by mood hash.
- Maintain offline-first journaling by default.
- Use robust failure messaging on AI/network/permission errors.
